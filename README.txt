PRABIR.DEV WEBSITE

FILES
- index.html: compact homepage
- websites.html: website catalogue, search and filters
- categories.html: category browser
- pricing.html: price list
- maintenance.html: plans and update request form
- about.html: about page
- faq.html: frequently asked questions
- contact.html: contact and social links
- admin.html: local demo admin dashboard

UPLOAD
Upload all HTML files together to the same hosting folder. Do not upload only index.html.

IMPORTANT
The current admin panel uses browser localStorage and is demo-only. Orders entered in a visitor browser do not automatically appear in your browser. For real shared orders, secure admin login, persistent uploads and customer records, connect a backend such as Firebase/Supabase. Do not store passwords or secret API keys in public HTML/JavaScript.

WhatsApp number is configured in the shared script. The public interface uses the WhatsApp link; the underlying wa.me link may reveal the business number.
